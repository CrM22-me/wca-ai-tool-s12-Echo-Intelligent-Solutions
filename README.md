# Echo Intelligent Solutions – Study Buddy

## Project Description

Study Buddy is an AI-powered learning assistant developed by **Echo Intelligent Solutions** under WCA AI Tool S12.

The project is designed to support students in their learning by providing an interactive study companion that helps them understand learning materials, organize study sessions, and review important information.

The system integrates artificial intelligence to make studying more interactive, efficient, and accessible.

## Key Features

- **AI Study Assistance:** Provides AI-powered support for learning and answering study-related questions.
- **Conversation Management:** Maintains study conversations for reference.
- **Memory Management:** Supports the organization and retention of relevant study context.
- **Study Summaries:** Helps generate summaries of learning materials and discussions.
- **Quiz Functionality:** Supports knowledge testing and revision.

## Technologies Used

- Python
- Google Gemini AI
- Google Generative AI
- Python-dotenv

## Project Structure

- `main.py` – Main application entry point.
- `ai_handler.py` – Handles AI interactions.
- `memory.py` – Manages study memory.
- `summary.py` – Handles study summaries.
- `quiz.py` – Quiz functionality.
- `requirements.txt` – Project dependencies.
- `samples/` – Sample project data.
- `conversations/` – Conversation storage.

## Installation

1. Clone the repository.
2. Install the required dependencies using:

```bash
pip install -r requirements.txt
```

3. Configure your Gemini API key in your environment variables.
4. Run the application using:

```bash
python main.py
```
